Quick answers

Do I have to install a collector?No. Contract data alone builds an inventory. But without telemetry most assessments and all AI insights either degrade or don't run.
Can I change my data storage region later?No. It's fixed at account creation. Changing it means a new company account from scratch.
Can I migrate from CX Cloud after creating an IQ account?No. Create fresh instead of migrating and that door closes permanently.
Are the security assessments AI-generated?No. Hardening, configuration and conformance checks are deterministic rule matching. The LLM only summarises and prioritises the results.
Does my data leave my region?In the US, no. In EMEA and APJC, a subset — the CLI data the models need — goes to the US for inferencing. This usually decides the deployment mode for regulated customers.
Can I run an assessment on demand?Not today. Rules evaluate during telemetry processing. Ad-hoc runs are tentatively 2HFY27.
Does multi-node give me high availability?No. It gives scale and GPU capacity. Lose the primary management node and cluster operations are impacted.
Can partners get in?Only through an early field trial today, inside the customer's account. Dedicated partner roles with per-partner data masking are FY27.

Known issues in the August 2026 release

  • Field notice affected-asset counts can read higher on the list than on the detail page. The detail page is correct.
  • Findings by Asset can show duplicates, and an asset can read "0 affecting" in the list while its detail view shows live advisories.
  • Security Hardening and Configuration sections on the Assessments overview intermittently vanish. Refreshing restores them.
  • An asset summary can show a field notice that the asset's own field notice page then reports as none detected.
  • Asking the AI Assistant for an exportable device list affected by a specific vulnerability can hang indefinitely.

Recently fixed: Intersight, Webex and Meraki first collection dropped from 24 hours to about one hour; quantum-safe assessments now return hardware refresh recommendations and correct metadata; the service-contract add error is resolved.

Lineage and neighbours

Cisco IQ succeeds CX Cloud. CX Cloud telemetry updates ceased for most customers on 14 August 2026 — the first stage of full end-of-availability — while partners retained access longer during transition. Migration is one-way, one account at a time, and carries users, groups, contracts and cloud data sources. There is no direct migration from SNTC. CSPC and CX Agent survive only inside migrated accounts and are pending end-of-support.

Cisco Cloud Control is the real-time operations console for the ops team. Cisco IQ is the lifecycle and advisory layer for the wider IT organisation. AI Canvas surfaces through Cloud Control, not IQ. IQ does not replace product dashboards like Nexus Dashboard or Intersight — it reads from them.
